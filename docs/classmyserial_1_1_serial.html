Detailed Description

Provides Linux serial port communication.

Serial wraps the POSIX termios API and supports runtime configuration, synchronous I/O with timeouts, and a background read thread driven by data and error callbacks.

Note
Serial objects cannot be copied, but they can be moved.
Unless otherwise stated, call lastError() after a method returns false or a negative value to obtain an error description.
